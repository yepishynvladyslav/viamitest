# VIAMI TEST — самостоятельный интерактивный прототип

**Версия:** V2 / 9 ноября 2026. Это не копия исходного кода VIAMI — доступ к репозиторию и Firebase-проекту не предоставлялся. Старое приложение не изменялось.

## Что уже можно проверить

- Новый анимированный экран приветствия и два сценария входа: демо и локальное создание профиля.
- Главная, адаптивная мобильная и десктопная навигация.
- Каталог из 6 демонстрационных поездок с поиском, избранным и фильтрами.
- Создание своего открытого объявления (сохранение в браузере), просмотр подробностей.
- Локальная заявка «Хочу присоединиться» и демонстрационное подтверждение участия.
- Групповой чат и голосование за даты (только на текущем устройстве).
- Маршрут поездки по Португалии с кнопкой «Начать день», отметками посещения, временем, добавлением точек, прогрессом.
- VIA AI — **демо-алгоритм** подбора комбинаций дат с ограничением длительности в днях и погрешностью, числом людей и бюджетом; условные цены и сохранённые запросы.
- Профиль с редактированием, экран объяснения проверки личности, чат поддержки и демонстрационная админ-панель.
- Сохранение локальных данных в localStorage, сброс демо.
- Офлайн SVG-заглушки вместо фотографий при отсутствии сети, PWA-манифест и service worker.

### Важные ограничения

Это **НЕ** настоящая система регистрации и авторизации. Apple/Google кнопки — только макет. Email и имя сохраняются на устройстве без отправки писем. Не вводите персональные секреты.

Билеты и цены **не являются реальными**: нет API авиакомпаний, Kiwi, eSky или других провайдеров, нет уведомлений в фоне. Группы и сообщения не синхронизируются между устройствами. Верификация личности, реальные оплаты, модерация и права администратора не подключены. Встроенная админ-панель демонстрационная, не настоящая защищённая консоль.

Некоторые фотографии и веб-шрифты загружаются из внешних общедоступных CDN. Если загрузка заблокирована, карточки используют встроенные SVG-иллюстрации.

## Самый быстрый просмотр на телефоне — через интернет

1. Распакуйте ZIP с проектом на компьютере.
2. Откройте `https://app.netlify.com/drop` и перетащите туда **папку** `viamitest` (именно папку, содержащую `index.html`, `style.css`, `app.js`).
3. Netlify выдаст отдельную HTTPS-ссылку вида `https://<имя>.netlify.app`. Это новый сайт и он не заменяет старый VIAMI.
4. Откройте ссылку на iPhone или Android. В Safari можете выбрать «Поделиться → На экран Домой».
5. Нажмите **«Посмотреть рабочее демо»**. Все действия на этой тестовой версии локальны.

Сайт станет доступен любому человеку с ссылкой. **Не загружайте реальные паспорта или персональные документы.**

## Посмотреть с телефона по домашнему Wi-Fi без публикации в интернет

### Windows 11
1. Распакуйте архив.
2. Откройте папку `viamitest`, дважды кликните `RUN_WINDOWS.bat`. Python должен быть установлен.
3. В другом окне командной строки выполните `ipconfig` и найдите **IPv4-адрес** компьютера для Wi-Fi, например `192.168.1.24`.
4. Подключите телефон к тому же Wi-Fi.
5. В Safari / Chrome откройте `http://192.168.1.24:8765` (вместо примера впишите свой IP).
6. Если телефон не подключается, проверьте разрешение Windows Firewall для Python в частной сети и не используйте гостевую сеть с изоляцией устройств.

Остановка сервера: Ctrl+C в окне, где он запущен.

### macOS / Linux
Запустите в папке проекта `python3 -m http.server 8765 --bind 0.0.0.0`, узнайте локальный IP и откройте на телефоне `http://<IP>:8765`.

По локальному HTTP установка полноценной PWA и офлайн-кеширование на телефоне могут быть ограничены. Для установки как веб-приложения используйте HTTPS (например, Netlify).

## Один HTML для быстрого просмотра

Рядом с ZIP предоставлен файл `viamitest-preview.html`, в котором CSS и JavaScript встроены непосредственно внутрь документа. На некоторых устройствах он откроется локально в браузере. Но браузеры iPhone могут ограничивать локальное выполнение JS и доступ к хранилищу, поэтому для **полноценного тестирования с телефона** лучше HTTPS или сервер Wi-Fi.

## Запуск локально на компьютере

В папке проекта:

```bash
python -m http.server 8765
```

Затем открыть `http://localhost:8765`.

## Для настоящего продолжения

Чтобы перенести рабочие функции оригинального VIAMI, нужны исходники Claude-проекта (ZIP/GitHub) и **тестовая** среда Firebase. Никогда не передавайте секретные ключи в чат. Следующий этап — реальный Firebase Authentication (Apple/Google, email link), Firestore Security Rules, групповые данные, backend поиска билетов через лицензированный API, уведомления и отдельные KYC-платежные интеграции.

## QA

Ручные автотесты в `tests/smoke_test.py` и `tests/extended_test.py` (Playwright, эмуляция мобильного и desktop Chromium; тестовый браузер в этой среде блокировал внешнюю сеть). `tests/persistence_test.cjs` проверяет сохранение локального аккаунта и отметки посещения при повторной инициализации JS с тем же хранилищем. Это НЕ означает, что на реальном iPhone проведена проверка или что система прошла security audit.

**Результат в тестовой среде:** основные сценарии GUI и расширенные сценарии завершились успешно, ошибок JavaScript в них не выявлено; отдельно проверено сохранение состояния. Проверить на реальных Safari и Android Chrome после публикации.
